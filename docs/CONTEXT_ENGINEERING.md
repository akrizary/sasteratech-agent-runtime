# Context Engineering

## Tier 0
Immutable controls: policy, approvals, permissions.

## Tier 1
Active goal, plan, blockers, evidence requirements.

## Tier 2
Canonical memory, relevant sources, active artifacts.

## Tier 3
Recent dialogue that materially affects the step.

## Tier 4
Auxiliary examples/background.

## Large corpus protocol
1. inventory
2. classify
3. chunk with overlap
4. track coverage
5. detect truncation
6. stitch cross-references
7. report unread areas

Coverage:
- FULL_COVERAGE_VERIFIED
- PARTIAL_COVERAGE
- SNIPPET_ONLY
- UNREADABLE

Compaction must preserve safety boundaries, active decisions, evidence refs, approvals, plan state and relevant failure history.
