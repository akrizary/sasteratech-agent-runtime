# Multi-Axis Routing v0.7

## Axes

### Domain
GENERAL, SOFTWARE, DATA, FILESYSTEM, CREATIVE, DATABASE, OPERATIONS, SECURITY.

### Procedure
EXPLAIN, RESEARCH, REVIEW, BUILD, DEBUG, ANALYZE, FILE_OPERATION, MIGRATE, CREATE, OPERATE.

### Action
NONE, READ, LOCAL_MUTATION, EXTERNAL_MUTATION, COMMUNICATION, FINANCIAL, DESTRUCTIVE, DEPLOY.

### Risk
R0–R4 is derived from actual requested action, not mere noun presence.

## Compatibility

`TaskClass` remains as a compatibility projection for existing role/workflow code. Future systems should increasingly route on the richer axes.
