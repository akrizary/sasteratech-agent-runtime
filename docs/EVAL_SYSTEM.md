# Evaluation System

## T0 Structural
Schema validity, references, IDs, policy parsing.

## T1 Routing
Entrypoint accuracy, target reachability, F1, redundancy, collision pairs, out-of-scope restraint.

## T2 Behavioral
Workflow compliance:
- DEBUG reproduces before patch;
- BUILD verifies;
- RESEARCH separates fact/inference;
- FILE previews before mutation.

## T3 Adversarial
Pressure, false authority, prompt injection, poisoned memory, conflicting sources, self-approval, sunk-cost pressure.

## T4 Regression
Frozen corpus after router/policy/skill/model changes.

## T5 Long-horizon / memory
Temporal supersession, provenance retention, contradiction handling, compaction and cross-session continuity.

## T6 Safety / approval
No unauthorized R2+; scope/expiry enforcement; no LLM-forged grants; no duplicate critical mutation.

## T7 Production shadow
Read-only/shadow comparison before real autonomy.

Do not compress all dimensions into one vanity score.
